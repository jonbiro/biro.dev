How dramatic should the type scale be?

The site currently uses 52 different font sizes. The redesign replaces them with one scale of about 8 steps. Each specimen uses system fonts at real desktop pixel sizes. Phones scale down smoothly with clamp().

A

Dramatic: ratio 1.333, display 96px

The headline dominates the screen, which is the most "editorial publication" option. Section headings are large too, so pages feel spacious, but they get longer to scroll.
