# Visual Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restyle the whole site to the approved editorial-plus-constellation design on a real token system, without changing copy or demo behavior.

**Architecture:**
- **Shared markup in `site_parts.py`.** New page parts live in `startup/site_parts.py`: status pills with per-label classes, a strip variant of "Where things stand", the "at a glance" column, inner-page heroes, the concept list and the constellation.
- **Tokens migrate in one step.** The token system replaces Foundation's tokens in a single task. That task rewrites `tokens.css`, `base.css`, `layout.css` and `media.css`, and mechanically migrates every other partial to the new names, so the stylesheet is consistent after every task.
- **Then components, then pages.** Shared components are rewritten next. Each page follows with its markup and partial together. Any new CSS is added in the same task as the markup that uses it, so `csskit check` (which rejects dead selectors) passes throughout.
- **Gates.** Guard tests pin tokens, colors and the font-size budget. New Playwright tests pin reduced motion, no-JavaScript visibility, reveal and the constellation pause.

**Tech Stack:** Python 3.9+ standard library; plain CSS (custom properties, `clamp()`, `:has()`); vanilla JavaScript (IntersectionObserver); the `startup/qa` Playwright toolkit.

**Spec:** `docs/superpowers/specs/2026-10-09-redesign-design.md`. Approved mockups are in `docs/superpowers/specs/redesign-mockups/`.

## Global Constraints

- **Branch:** `claude/redesign`, stacked on `claude/messaging`. Open the pull request against `claude/messaging`, and never merge it without the user's explicit instruction.
- **No copy changes.** Every text segment added in the generated HTML must be a case-insensitive substring of the text on `claude/messaging`'s site. Exceptions: the status label `Concept` on Home rows, and the "at a glance" field labels (`At a glance`, `Company`, `Founder`, `Based in`, `First product`, `Stage`, `Design target`, `Commitments`, `This website`, `Email`, `Target`, `Reviewed`, `Tested in`, `Not yet verified`). Removed segments are allowed only for:
  - About's "Company at a glance" section
  - Home's hero concept card and visual caption
  - the Products card "Explore …" links
  - the related-product card markup on product pages
- **Tokens:** exactly the set in spec section 1, defined only in `startup/styles/tokens.css`. That file also holds the high-contrast override block. No hex color appears in any other partial.
- **Font sizes:** the generated `site.css` uses at most 12 distinct `font-size` values: the 8 type tokens plus the print sizes.
- **Demo:** behavior and announcements are unchanged (`concept-model.js` untouched). `site.js` gets only additive reveal and pause code, and `node check-concept.cjs` plus the QA `demo` tests pass unchanged.
- **Accessibility:** `npm --prefix startup/qa test` passes with **no new `known-issues.json` entries**.
- **Unchanged:** routes, redirects, `netlify.toml`, page `<head>` metadata and images.
- **Test commands:**
  - Python: `cd startup && python3 generate.py >/dev/null && python3 -m unittest discover -s tests -p 'test_*.py' && python3 -m unittest discover -s tools -p 'test_*.py'`
  - Style rules: `cd startup && python3 tools/csskit.py check dist/assets/site.css --html dist`
  - Browser: `npm --prefix startup/qa test`
  - Demo model: `cd startup && node check-concept.cjs`
- Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Snapshot determinism with an endless animation and a scroll-triggered reveal on the page.** Two captures of the same build must stay identical. Pinned by the determinism check in Task 4, Step 5.
2. **No JavaScript, or JavaScript that fails to run.** Every section must still be visible; the reveal must never hide content by default. Pinned by the no-JS Playwright test in Task 4, Step 1.
3. **A visitor who turns on reduced motion.** No animation, transition or hover movement anywhere. Pinned by the reduced-motion Playwright test in Task 4, Step 1.
4. **Phone widths between the breakpoints (320–600px).** No horizontal overflow from the larger type, the constellation or hero grids. Pinned by the existing audit at 320 and 375px plus the snapshot band widths, run in every task's gate.
5. **Headings that use `<br>` for desktop line breaks.** When the breaks are hidden on phones, words must not run together. Pinned by the unit test in Task 2, Step 1.

```python
def glance(rows: list) -> str:
    """The ruled "at a glance" column for inner-page heroes. Values are HTML (links, pills)."""
    items = ''.join(f'<div><dt>{escape(term)}</dt><dd>{value}</dd></div>' for term, value in rows)
    return f'<aside class="glance" aria-label="At a glance"><p class="eyebrow">AT A GLANCE</p><dl>{items}</dl></aside>'


def inner_hero(eyebrow: str, title_html: str, intro_html: str, aside: str = '', below: str = '') -> str:
    return (f'<section class="page-hero wrap"><div class="hero-grid"><div><p class="eyebrow">{eyebrow}</p>'
            f'<h1>{title_html}</h1><p class="intro">{intro_html}</p></div>{aside}</div>{below}</section>')


def concept_list(items: list, detailed: bool = False) -> str:
    """Ruled rows linking to each product page: icon, name, category and its status label."""
    rows = []
    for item in items:
        slug, name = item['slug'], escape(item['name'])
        icon = (f'<img class="app-icon" src="/assets/products/icons/{slug}.webp" alt="" width="56" height="56" '
                'loading="lazy" decoding="async">')
        tail = status_pill(item.get('status', 'concept')) + '<span class="concept-row-arrow" aria-hidden="true">→</span>'
        if detailed:
            text = (f'<span class="concept-row-text"><span class="eyebrow">{escape(item["category"])}</span>'
                    f'<h3 id="{slug}-title">{name}</h3><span class="concept-row-tagline">{escape(item["tagline"])}</span>'
                    f'<span class="concept-row-description">{escape(item["description"])}</span></span>')
            rows.append(f'<li id="{slug}" tabindex="-1"><a class="concept-row concept-row-detailed" href="/{slug}/" '
                        f'aria-labelledby="{slug}-title">{icon}{text}{tail}</a></li>')
        else:
            text = f'<span class="concept-row-text"><strong>{name}</strong><span>{escape(item["category"])}</span></span>'

    return '<ul class="concept-list" role="list">' + ''.join(rows) + '</ul>'
```

`startup/heading_breaks.py`:

```python
"""Headings use <br> for desktop line breaks; phones hide them, so each break needs a space before it."""
import re

HEADING = re.compile(r'<(h[1-3])\b([^>]*)>(.*?)</\1>', re.S)


def heading_breaks(html: str) -> str:
    return HEADING.sub(lambda m: f'<{m[1]}{m[2]}>' + re.sub(r'(?<=\S)<br>', ' <br>', m[3]) + f'</{m[1]}>', html)
```

```python
def migrate(value: str, prop: str, where: str) -> str:
    value = re.sub(r'var\((--[\w-]+)\)', lambda m: f'var({RENAME.get(m.group(1), m.group(1))})', value)
    def hex_color(m):
        key = m.group(0).lower()
        if key not in HEX:
            raise SystemExit(f'Unmapped color {key} in {where}')
        return HEX[key]
    value = re.sub(r'#[0-9a-fA-F]{3,8}\b', hex_color, value)
    if prop == 'font-size' and not value.startswith('var(--type-'):
        if value not in FONT:
            raise SystemExit(f'Unmapped font-size {value} in {where}')
        value = FONT[value]
    return value

        continue

    for node in nodes:
        if isinstance(node, ck.Rule):
            node.decls = [ck.Decl(d.prop, migrate(d.value, d.prop, f'{path.name} {node.selector}'), d.important) for d in node.decls]
    path.write_text(ck.serialize(nodes))
    print('migrated', path.relative_to(STYLES))
```

```js
// Section reveal: additive and optional. Sections stay visible without JavaScript or under reduced motion.
(() => {
  'use strict';
  if (!('IntersectionObserver' in window) || window.matchMedia('(prefers-reduced-motion: reduce)').matches) return;
  const sections = document.querySelectorAll('main > *');
  if (!sections.length) return;
  document.documentElement.classList.add('js-reveal');
  const reveal = new IntersectionObserver((entries) => {
    for (const entry of entries) {
      if (entry.isIntersecting) {
        entry.target.classList.add('is-visible');
        reveal.unobserve(entry.target);
      }
    }
  }, { rootMargin: '0px 0px -8% 0px' });
  sections.forEach((section) => reveal.observe(section));
})();
```

```js
// Pause the constellation's drift while it is off-screen or the tab is hidden.
(() => {
  'use strict';
  const orbits = document.querySelectorAll('.constellation');
  if (!orbits.length || !('IntersectionObserver' in window)) return;
  const visible = new Map();
  const update = (orbit) => orbit.classList.toggle('is-paused', document.hidden || !visible.get(orbit));
  const watch = new IntersectionObserver((entries) => {
    for (const entry of entries) {
      visible.set(entry.target, entry.isIntersecting);
      update(entry.target);
    }
  });
  orbits.forEach((orbit) => watch.observe(orbit));
  document.addEventListener('visibilitychange', () => orbits.forEach(update));
})();
```
