# Biro.dev startup website

Fourteen public pages introducing Jonathan Biro’s assistive technology company, AddvancedFocus, and eight future products. The AddvancedFocus website demo is scripted, with no live AI requests or persistent user data.

Netlify builds this directory with `python3 generate.py` and publishes `dist/`. The earlier portfolio source is preserved at the repository root. Public contact: founder@biro.dev. Canonical domain: https://biro.dev.

Product pages use WebP mockups and JPEG social images. Original PNG artwork and the self-contained review archive were retained separately during design. No customer, funding, partnership, launch-date, or released-product claims are made.
